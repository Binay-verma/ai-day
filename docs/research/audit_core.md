## Checked and found correct (negative results)

* **Letterbox and NMS mapping:** boxes match Ultralytics exactly (max |Δ| = 0.000 px) when run on the same ONNX file (r02b). The per-class offset NMS trick is correct for 640 px inputs, because offset 4096 is larger than any coordinate. Class order `[smoke, fire]` matches the model metadata.
* **Conformal quantile:** `ceil((n+1)(1-α))` with `s[k-1]` is the correct finite-sample rank. No float/exact mismatches were found for α ∈ {0.01…0.3}, n < 400 (r09 R10). `n_required = ceil(1/α - 1)` is consistent with that rank.
* **Counterfactual math:** the inverse is correct with reliability and weight sign. The range check rejects values that would be clipped. One-sided cues (lo == ref) behave correctly. Attribution exactness holds (the test passes). The defect is in what gets explained (C6), not in this math.
* **Eigen-CAM unletterbox:** consistent with the letterbox rounding. A constant CAM gives a NaN correlation coefficient, which is handled without crashing.
